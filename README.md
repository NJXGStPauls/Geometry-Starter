# Geometry: starter project

This is the starting point for the Introduction to Classes worksheet. It is a C# solution with two projects:

- **Geometry.Lib**: a class library containing the `Triangle` class
- **Geometry.App**: a console app that creates and uses triangles

## Getting the code

**If you have Git installed**, clone the repository:

```
git clone https://github.com/NJXGStPauls/Geometry-Starter.git
```

**If you do not**, click the green **Code** button above, choose **Download ZIP**, and unzip the folder.

## Opening and running it

1. In VS Code, choose **File**, then **Open Folder**, and open the `Geometry-Starter` folder.
2. If VS Code asks whether you trust the folder, click **Trust**.
3. Open a terminal in VS Code and run:

```
dotnet run --project Geometry.App
```

You should see the details of two triangles printed. Now carry on with the worksheet, adding to `Triangle.cs` and creating new classes in `Geometry.Lib`.
